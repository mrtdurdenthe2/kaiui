# kaiui

This repository is the source of truth for Kai Wilson's UI style.

Agents should read this repository before building UI for Kai. Follow what is written here. Do not invent a parallel style, a second token set, or stand-in components.

The style guide has started in [docs/style-guide.md](docs/style-guide.md). Record only what Kai writes there. Do not invent the rest of the system.
